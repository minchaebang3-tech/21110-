# 21110-

한국중부발전의 신재생에너지 발전량 공공데이터를 활용하여 발전 현황을 시각화하고 이용률을 통해 설비별 발전 효율을 비교할 수 있는 웹 분석 대시보드이다.

1. 프로젝트 소개

신재생에너지 발전량 공공데이터는 설비별, 날짜별로 많은 정보가 쌓여 있어 표만으로는 발전량의 변화와 패턴을 파악하기 어렵다. 또한 발전설비마다 용량이 다르기 때문에 총 발전량만으로는 설비의 효율을 공정하게 비교하기 어렵다. 이러한 문제를 해결하기 위해 데이터를 그래프로 시각화하고, 설비용량 대비 실제 발전량의 비율인 이용률을 함께 확인할 수 있는 대시보드를 제작했다.
코딩 없이 신재생에너지 발전 현황과 설비별 발전량을 쉽게 확인하고 싶은 학생과 일반 시민을 대상으로 하는 앱이다.
Streamlit으로 웹 화면을 구성했다. 완성한 프로그램은 Streamlit Community Cloud를 통해 배포했다.
사용한 데이터는 공공데이터포털(data.go.kr)에 공개된 한국중부발전(주)의 신재생에너지 발전량 데이터를 사용했다. 주요 항목은 연월일, 발전설비, 설비용량, 발전량이다. 설비별 이용률은 실제 발전량을 설비용량과 하루 시간인 24시간의 곱으로 나눈 뒤 100을 곱하여 계산했습니다.

2. 사용법

앱을 실행하면 메인 화면에 일별, 월별, 순위, 지역별 분석 버튼이 나타난다. 원하는 분석 버튼을 누른 후 왼쪽 사이드바나 화면 위쪽에서 발전설비와 기간을 선택하면 그래프와 표를 확인할 수 있다. 분석 화면 위쪽의 '메인으로 돌아가기' 버튼을 누르면 메인 화면으로 이동할 수 있다. 월별 이용률 히트맵과 사용 설명서는 왼쪽 사이드바 메뉴에서 선택하여 이용할 수 있다.

3. 주요 기능 


일별 발전량: 발전설비와 날짜 범위를 선택하면 총 발전량, 일평균 발전량, 평균 이용률을 확인할 수 있다. 또한 날짜에 따른 발전량 변화를 그래프와 데이터 표로 보여준다.
월별 발전량: 시작 월과 종료 월을 선택하면 해당 기간의 발전량을 월별로 묶어 막대그래프로 비교할 수 있다.
발전 설비별 순위: 선택한 기간 동안 총 발전량이 많은 발전설비를 순위로 보여준다. 사용자가 원하는 설비 수를 선택하여 결과를 확인할 수 있다.
지역별 발전량: 원본 데이터에 지역을 나타내는 항목이 없어 발전설비 이름의 앞부분을 기준으로 지역을 추정하고, 이를 바탕으로 지역별 발전량을 비교했다.
이용률 히트맵: 원하는 월을 선택하면 발전설비별 이용률을 색상으로 구분하여 비교할 수 있다. 선택한 데이터에 맞춰 결과 요약 3줄이 자동으로 생성되며, 그래프 오른쪽 위의 카메라 아이콘을 이용하면 요약이 포함된 이미지를 저장할 수 있다.

4. 이용방법

배포된 Streamlit 웹사이트 주소에 접속하면 신재생에너지 발전량 분석 대시보드의 메인 화면이 나타난다. 메인 화면에는 일별 발전량, 월별 발전량, 발전설비별 순위, 지역별 발전량을 확인할 수 있는 분석 버튼이 있다.
원하는 분석 버튼을 클릭하면 해당 분석 화면으로 이동한다. 일별 발전량에서는 발전설비와 날짜 범위를 선택할 수 있고, 월별 발전량에서는 발전설비와 시작 월 및 종료 월을 선택할 수 있다. 발전설비별 순위에서는 비교 기간과 그래프에 표시할 설비 수를 조절할 수 있으며, 지역별 발전량에서는 비교 기간을 선택하여 지역별 발전량을 확인할 수 있다.
각 화면에서는 선택한 조건에 따른 그래프와 데이터 표를 확인할 수 있다. 분석 화면 위쪽의 '메인으로 돌아가기' 버튼을 누르면 처음 화면으로 이동할 수 있다.
월별 이용률 히트맵과 사용 설명서는 왼쪽 사이드바에서 선택할 수 있다. 히트맵에서는 원하는 월을 선택하여 설비별 이용률을 색상으로 비교하고, 자동 생성된 결과 요약을 확인하거나 그래프 이미지를 저장할 수 있다. 사용 설명서에서는 프로그램 소개와 각 기능의 이용 방법을 확인할 수 있다.
